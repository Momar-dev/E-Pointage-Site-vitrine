# E‑Pointage — Système anti‑fraude de pointage

![E-Pointage Banner](assets/banner.svg)

**Résumé**
Application mobile et backend pour la gestion de pointage sécurisé en entreprise : QR codes dynamiques, device fingerprinting et administration en temps réel.

🔹 Tech : React Native (Expo) · Node.js · SQLite · SSE / WebSockets

🔹 Fonctionnalités clés :
- Génération de QR codes éphémères côté serveur
- Validation hors ligne / mise en cache côté mobile
- Empreinte device pour réduire la fraude
- Dashboard admin pour visualiser présences et exports CSV
